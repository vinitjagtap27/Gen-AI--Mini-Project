# Customer Feedback Classifier

## Problem Statement
Customer feedback forms pile up unread, making it difficult to spot urgent issues. This project classifies customer feedback from an uploaded CSV into categories (**delivery**, **quality**, **price**) along with a **priority** level per row, lets users filter the results table by category, and allows downloading the classified results.
